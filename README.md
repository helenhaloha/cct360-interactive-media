# Lab 5: Interactive Media

## Toronto First Snow

This project combines an original 75-second winter soundscape with an interactive webpage.

### Part A — Soundscape

The audio file was created specifically for this project. It represents a snowy winter walk in Toronto and includes synthesized winter wind, footsteps in snow, a streetcar bell, a crosswalk signal, and a passing streetcar.

### Part B — Visualscape

- HTML5 audio controls
- A frequency visualizer drawn on canvas
- Snow and skyline brightness that respond to the audio
- Pointer movement that changes the skyline position
- Three user-selectable snowfall modes
- Dynamic chapter text based on audio playback time

All HTML, CSS, JavaScript, SVG, and audio media files are included in the repository.
